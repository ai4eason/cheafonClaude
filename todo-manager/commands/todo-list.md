列出所有 TODO 待办事项。

## 操作步骤

1. 运行以下命令获取所有 TODO：

```bash
node ${CLAUDE_PLUGIN_ROOT}/scripts/todo.js list
```

2. 命令输出 JSON 数组，将其格式化为易读的列表展示给用户：
   - 未完成的待办在前，已完成的在后
   - 未完成条目显示：ID、`⬜` 标记、标题、创建日期
   - 已完成条目显示：ID、`✅` 标记、标题、完成时间、用时
   - 用时根据 `createdAt` 和 `doneAt` 计算，格式规则：
     - < 1 小时：`Xm`
     - < 1 天：`Xh Ym`（分钟为 0 时省略）
     - >= 1 天：`Xd Yh`（小时为 0 时省略）
   - 底部显示统计信息（待完成/已完成/总计）

3. 如果没有任何 TODO，告知用户可以用 `/todo-manager:todo-add <标题>` 添加

## 输出格式示例

```
待办事项列表：

⬜ #1 买牛奶 (02-28)
⬜ #3 写周报 (02-28)
✅ #2 回复邮件 (完成于 02-28 09:00, 用时 17h30m)

共 3 条：2 待完成，1 已完成
```
